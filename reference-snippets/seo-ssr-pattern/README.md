# SEO SSR Pattern

## Purpose

Reference for public web projects that need strong search visibility.

## What to reuse from the current project

- `SeoService`
- route metadata
- SSR server pattern
- `robots.txt`
- `sitemap.xml`

## When to use it

- corporate websites
- content platforms
- landing pages
- any public product that depends on search discovery

## What must change when moving it

- text content
- canonical domain
- route map
- structured data schema
